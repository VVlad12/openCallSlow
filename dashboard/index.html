Windows records hourly network use per app (SRUM). It has no destinations and includes local-network traffic.

Reading these numbers

  • Bytes are counted per program at the network stack, so they include protocol overhead but not Wi-Fi/Ethernet framing.
  • Domains come from the DNS lookups programs make. If your browser uses “secure DNS” (DNS-over-HTTPS), its traffic falls back to the network operator.
  • With a VPN, traffic may be counted twice: once inside the tunnel, once as the VPN's own traffic.
  • Local-network traffic (printer, NAS, other devices at home) is shown separately and is not part of the internet total.
